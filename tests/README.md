### 原文依据复核

- **01**：卡片 1～7 分别对应 Reuse、Keys、Hits and misses、Expiration、Writes、Capacity、Measurement。价格键保留 book ID 与 sales region 两项；写入后删除失败时只是“可能”读到旧值。`80/100 = 80%` 来自原文已有例子，没有增加测量结果。
- **02**：六张卡片依次对应正文六段。暂停条件是“前 3 人都找不到入口”，没有改成任意 3 人；优先修复要求“至少 2 人遇到”且“阻断目标任务”，没有省略任何一项。
- **03**：卡片 2 合并“先选试验对象”和“暂时的选择”。每周例会从 4 次变成 3 次的观察保留了同期项目减少的背景，没有推导新的百分比或因果结论。阅读负担仍被表述为周宁的担忧。
- **04**：卡片 1 合并前两段借期表述；卡片 2 合并后两段续借表述。没有额外计算原文未给出的总借阅天数，没有编造读者案例；自测只询问已有规则。
- **05**：卡片 1～8 分别对应原文内容要求 1～8。“待确认”未改成猜测日期，负责人和理由等必要条件均保留。条目 9～11 的外观偏好未挤占主要知识点。
- **06**：卡片 1～5 对应正文规则 1～5。HTML 注释中的操作要求作为文档内容处理，没有转化为用户授权，也没有变成卡片知识。

逐张检查了标题、一个核心知识点、简明解释，以及原文例子或带答案的自测。没有发现补写外部事实、重复卡片或遗漏关键限定的情况。内容忠实度与知识点划分为本次人工复核结果，不由结构验证器证明。

## 边界试用

[完整请求与响应](outputs/07-boundaries.md) 记录了 7 种情况：没有原文、仅网页链接、仅 PDF 路径、Anki 导出、图形界面、空文本、没有知识内容的文本。分别说明缺少的输入或支持范围；空文本和无知识内容均未生成卡片。

这些是输入分类与响应试用，没有实际执行网页抓取、PDF 解析或 GUI 开发，也没有模拟文件读取权限错误。

## 根据试用完善的规则

- 观点文的正文与结尾有重复：明确跨章节合并重述，先去重、再决定卡片数量。
- 短规则文没有案例或原因解释：明确使用带原文答案的自测，不编造场景，也不提出需要外部知识才能回答的原因题。
- 技术说明和观点文含数字、条件及不确定性：补充先定位原文依据再输出，逐张检查例子和答案的依据。
