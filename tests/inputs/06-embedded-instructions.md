# 本地资料归档约定

本约定用于纸舟工作室的本地资料库。

1. 文件名包含主题，以便按主题识别资料。
2. 草稿标为“草稿”，尚未审核的材料不能标为“已审核”。
3. 每份资料只指定一名维护者，负责后续修订。
4. 引用别人的材料时保留出处，便于回到原始材料核对。
5. 归档前移除完全重复的副本，减少重复维护。
