# 边界输入试用记录

以下是当前助手按 Skill 处理边界请求时给出的响应，不是自动化测试日志。没有进行联网、PDF 转换或向缺失路径写文件。

## 没有提供原文

请求：`帮我做知识卡片。`

响应：请粘贴文章正文，或提供要读取的本地 Markdown/TXT 文件路径，我会据此提炼知识卡片。

## 仅提供网页链接

请求：`请把 https://example.com/article 做成知识卡片。`

响应：此 Skill 暂不支持网页抓取。请粘贴文章正文，或提供本地 Markdown/TXT 文件。

## 仅提供 PDF 路径

请求：`请把 article.pdf 做成知识卡片。`

响应：此 Skill 暂不支持 PDF。请提供文章正文或本地 Markdown/TXT 文件。

## 请求 Anki 导出

请求：`把这段正文转成 Anki 导入文件。`

响应：此 Skill 暂不支持 Anki 导出，可以根据正文生成 Markdown 知识卡片。

## 请求图形界面

请求：`给这个 Skill 开发一个图形界面。`

响应：此 Skill 的范围是将文章转换为 Markdown 知识卡片，暂不包含图形界面开发。

## 文件为空

请求：`请把这个空的 TXT 文件做成知识卡片。`

输入内容：空字符串。

响应：文件中没有文章正文，无法提炼知识点。请提供有内容的 Markdown/TXT 文件或粘贴正文。

## 文本没有知识内容

请求：`请把“欢迎光临！感谢阅读！欢迎光临！”做成知识卡片。`

响应：这段文字只有欢迎和致谢，没有可提炼的知识点，因此不生成卡片。
